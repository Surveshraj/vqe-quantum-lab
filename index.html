How to Deploy this VQE App on Vercel

Step-by-step instructions to launch your Quantum Lab live on the web

1 Option A: Deploy using Vercel CLI (Recommended)

Run the following commands in your project folder:

npm install -g vercel
vercel login
vercel

2 Option B: Deploy via GitHub Integration

  1. Push this folder to a new GitHub repository.
  2. Go to vercel.com/new.
  3. Import your repository and click Deploy. Vercel automatically detects the HTML & Serverless Python API.
Included Vercel Configurations:
  • vercel.json - Serverless Python routing for api/vqe.py.
  • requirements.txt - Pre-configured dependencies for backend API.
  • index.html, styles.css, app.js - Zero-dependency fast frontend.
